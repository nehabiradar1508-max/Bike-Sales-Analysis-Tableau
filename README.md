# Bike Sales Analysis Dashboard – Tableau

## Project Overview

This project presents an interactive Tableau dashboard created to analyze bike sales performance across products, customer demographics, countries, and time periods.

## Objective

The objective of this project is to identify sales and profit trends, understand customer segments, analyze product performance, and explore geographic sales patterns.

## Tool Used

- Tableau

## Dashboard Preview

![Bike Sales Dashboard](Bike-Sales-Dashboard.png)

## Key Analysis

The dashboard analyzes:

- Profit and revenue
- Year-over-year change
- Top 10 products by quantity sold
- Product category performance
- Sales by gender
- Sales by age group
- Sales by country
- Year-wise trends

## Interactive Features

- Year parameter
- Country filter
- Interactive dashboard visualizations
- Product and customer-level analysis

## Key Insights

- Identify the highest-selling products.
- Compare performance across product categories.
- Analyze purchasing patterns across different age groups and genders.
- Compare sales performance across countries.
- Observe changes in sales and profit over time.
